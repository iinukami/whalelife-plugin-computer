# 电脑与文件

WhaleLife 的 Windows 本地文件插件。通过网页逐项授权后，鲸鲸可以查找资料、编辑文件、生成文档，并在隔离环境中运行离线 Node 脚本。

当前版本 0.1.1，补充写后回读核验，并区分内容原本相同的保存。所有能力默认关闭，工作范围默认是插件自己的 `data/workspace`。启用插件不会自动执行文件任务。设置入口为宿主控制台的「电脑与文件」，地址 `/plugins/computer/settings`。

## 已实现的能力

| 能力 | 行为 |
| --- | --- |
| 文件读取 | 列出目录、按名称或 UTF-8 正文搜索、分页读取文本 |
| 文件写入 | 创建目录、创建文件、按版本覆盖、唯一文本替换 |
| 删除与恢复 | 删除单个普通文件前保留副本，按副本编号恢复；不提供递归删除目录 |
| 文档 | 用标题及文字段落生成 DOCX、Markdown 或 HTML；不是完整 Office 排版编辑器 |
| 离线执行 | Node 脚本及可在 Windows 隔离策略内运行的子命令；返回真实退出码、有界输出和导出结果 |
| 文件交付 | 已认证 Web 下载，链接绑定当前会话和文件版本，30 分钟有效 |

读取、写入、删除、恢复、执行、安装任务依赖、管理系统软件、允许自主调用分别勾选。安装任务依赖与管理系统软件目前仅保存授权，尚无受控安装器，勾选不表示安装功能已经可用。PowerShell 在当前 LPAC 策略下未通过启动验收，公开入口不开放。

QQ 的公开私聊媒体接口 `sendMedia` 仅支持文本和图片，尚无通用文件发送契约。QQ 中生成文件可以保存在工作目录，但不能直接交付为 QQ 文件；请求发送时明确返回未发送，可转到 Web 下载。联网获取延后复用网上冲浪插件；桌面截图、点击和键盘输入不在此版本内。

## 授权与范围

模型工具 `computer_task` 要求主干工具权限为 `full`，并通过本插件的能力勾选。允许的来源为主干 Web、通过 QQ 公开白名单工具核验的当前私聊用户，以及单独开启自主调用后来自自主性插件的任务。身份取自宿主提供的会话，不接受模型在参数中填写身份或权限。

网页手动操作代表已通过宿主认证的用户指令，直接受本插件勾选约束，不需要模型工具权限。网页沿用宿主认证，不单独实现账户系统。此插件不是对恶意宿主或恶意插件的安全边界。

目录范围可以选「工作目录」或「全部本地文件」。全部本地文件仍受 Windows 当前账户权限和受保护目录限制；不授予管理员权限。宿主目录、插件自身数据和备份目录不能经通用文件接口改写。只有固定的自有工作目录可作为插件私有目录内的文件区例外。自定义工作目录需先存在，并且不能与受保护目录重叠。

拒绝网络共享、设备路径、备用数据流、盘符相对路径、目录穿越、符号链接、目录联接、短路径别名和硬链接文件。文件检查针对普通文件任务，并非内核句柄级防护；不能抵抗同一 Windows 账户下恶意程序并发替换目录的竞态。

一次调用的 1–16 个固定动作构成一项任务。开始时保存授权及目录快照；取消勾选不打断已经开始的批次，排队和新任务会重新核验。显式取消、超时、插件停用和宿主关闭仍然生效。当前宿主没有公开跨工具调用的整轮执行标识，因此多次工具调用不能沿用一次旧授权。批次不是事务，失败前已完成的动作会保留并报告，不自动重放。

## 文件、副本与输出

覆盖或删除现有文件前，先读取并提供该版本的 SHA-256；冲突时拒绝覆盖。创建可使用 `createOnly: true`。覆盖、删除和覆盖式恢复均在修改前保存旧版本，副本失败则不修改原文件。

写入、编辑、恢复或脚本输出导入的目标内容如果与现有文件逐字节相同，仍须通过版本及创建条件检查，然后返回 `unchanged`：内容已相同，本次未改写，不新增副本或改变文件修改时间。真正写入后会读回最终文件核验；成功结果的字节数和 SHA-256 来自该次读回，并标记 `verified: true`。核验失败时任务失败，提示目标可能已改变，保留已有副本和此前完成项；应先读取核对，不自动重试或回滚。核验仅说明当次读到的内容，不保证其他程序随后不会修改文件。

默认副本保留 30 天、容量 1 GiB，网页可调整。每次创建新副本时，按最旧优先清理过期或超容量的本插件副本；没有后台清理定时器。不会清理其他目录的备份。需要副本的修改在备份归属或索引异常时失败；无索引的副本正文需先人工核对，不能直接删除未知副本来继续任务。副本容量不足以保存一个文件时，该次修改失败。

默认单文件处理上限 16 MiB，任务超时 120 秒；可调整至单文件 64 MiB、任务 300 秒以内。搜索最多处理 10,000 个通过路径检查的条目、32 MiB 正文，另有每目录枚举上限及 32 层深度限制；底层枚举次数可能更多。正文读取使用 UTF-16 字符位置分页，结果会报告截断。文件写入正文与脚本另有请求大小上限，详见 [接口契约](CONTRACT.md)。

脚本只接收显式 `inputs` 的副本。执行期间不能直接修改原文件；只有正常退出且退出码为 0 后，才按显式 `outputs` 映射检查、备份并导入文件。删除临时输入不等于删除原文件。多文件导入可能部分成功，临时执行结果保留已保存项及错误；清理失败不报告完整成功。

下载链接不是文件快照：下载时重新核验会话、当前读取授权、路径范围及文件摘要；文件改变后需要重新生成链接。删除或关闭读取权限会使原链接失效。

插件不记录文件正文、脚本或命令输出到业务日志。工具正文走主干临时工具协议，持久回执只保留任务编号、状态、动作及成功标记。备份当然保存恢复所需的旧文件内容。主干若另外启用完整诊断采集，其日志策略由主干管理，本插件不能承诺那类诊断不保存请求和响应。

## Windows 执行

需要 Windows 10/11 x64、Node 24.22.1 或更高版本，以及本机构建的 .NET Framework 原生执行代理。Node 脚本是首版验收通过的运行时。没有原生代理或启动隔离失败时，执行能力明确失败，不退回普通 shell。

执行代理采用 LPAC、无网络 capability、独立临时目录及 Job Object。唯一系统能力是初始化所需的 `registryRead`，启动前校验令牌；系统本身已向 LPAC 开放的资源仍可访问。无全局防火墙修改、不改变原文件 ACL。具体边界、清理方式和官方依据见 [原生代理说明](native/README.md)。

Node 子命令使用 `stdio: 'inherit'`；默认 Windows 子进程管道在此 LPAC 环境中可能卡住，随后由超时终止。能运行哪些本地程序取决于其 LPAC 兼容性与原有系统 ACL，不承诺任意已安装软件均可运行。最大文件大小约束检查和导入，不是临时目录的磁盘配额。

## 开发、检查与构建

本版声明支持的最低宿主为提交 `13bf1746a814c71e0faafa27e0d222504291401c`；开发时另核对当前宿主。使用公开 `whalelife` 类型和插件接口；不承诺更早版本兼容。缺少 `registerTransient` 时停用整项能力，不降级为普通工具。

安装开发依赖后，指定公开宿主源码目录，再检查和构建：

```powershell
npm ci
$env:WHALELIFE_SDK = 'C:\source\whalelife'
npm run check
npm test
npm run build
```

构建使用本机已有 .NET Framework C# 编译器，不在线下载运行时。发行目录为 `dist/computer`，含源码、原生代理、许可证及逐文件 SHA-256 的 `BUILD.json`，不含配置、工作文件或备份。源码仓库不跟踪生成的 EXE。

默认测试不创建原生 AppContainer。Windows 隔离专项需在允许创建临时 AppContainer profile 的开发环境显式开启：

```powershell
$env:WHALELIFE_NATIVE_TESTS = '1'
node --test --test-concurrency=1 tests/executor.test.ts
Remove-Item Env:WHALELIFE_NATIVE_TESTS
```

回归只使用合成文件、临时本地监听器和自有随机 profile。测试目录集中在 `.artifacts/tests` 并清理；正式账户、模型和用户文件不参与。

源码完成、构建完成、正式安装和实际任务验收是不同状态。此开发交付没有安装或重启正式宿主；需要部署时仅同步经核对的 `dist/computer`，保留现有插件数据。
